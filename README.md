# SANG | Military Academy

Публичный многостраничный сайт для GitHub Pages. Каждая категория открывается как отдельный HTML-документ.

## Страницы

- `index.html` — главная.
- `academy.html` — правила.
- `leadership.html` — руководство.
- `rules.html` — подразделения.
- `promotions.html` — система повышения.
- `exams.html` — экзамены и присяги.
- `materials.html` — устав и законопроекты.

Общие файлы:
- `style.css` — единое оформление и мобильная адаптация.
- `script.js` — мобильное меню, кнопка «наверх» и поиск материалов.
- `.nojekyll` — отключает обработку Jekyll.

## Публикация через GitHub Pages

1. Создайте **Public** репозиторий, например `sang-military-academy`.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите `Deploy from a branch`.
5. Укажите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации сайт будет доступен по адресу:
   `https://ВАШ-ЛОГИН.github.io/sang-military-academy/`
