# SANG | Military Academy

Публичный статический сайт для GitHub Pages. Проект не требует сервера, базы данных или сборки.

## Состав проекта

- `index.html` — страницы и содержимое сайта.
- `style.css` — оформление и адаптация под мобильные устройства.
- `script.js` — навигация, мобильное меню и поиск.
- `.nojekyll` — отключает обработку Jekyll для статических файлов.

## Публикация через GitHub Pages

1. Войдите в GitHub и создайте новый репозиторий, например `sang-military-academy`.
2. Для публичного сайта выберите видимость **Public**.
3. Загрузите в корень репозитория файлы `index.html`, `style.css`, `script.js` и `.nojekyll`.
4. Откройте репозиторий → **Settings** → **Pages**.
5. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Нажмите **Save** и подождите завершения публикации.
7. В разделе Pages появится публичная ссылка примерно такого вида:
   `https://ВАШ-ЛОГИН.github.io/sang-military-academy/`

Если хотите адрес короче вида `https://ВАШ-ЛОГИН.github.io/`, назовите репозиторий точно `ВАШ-ЛОГИН.github.io`.

## Что нужно отредактировать перед публикацией

- В `index.html` уточните должность Larry Uzix.
- Замените текст-заглушку Discord-контакта Morph Hurtzon на точный контакт или ссылку.
- Добавьте контакты остальных руководителей, если это необходимо.
- Замените демонстрационные общие положения на актуальный устав и регламент вашего RP-сервера.
- Добавьте реальные требования для каждого повышения и ссылки на учебные документы.
- При необходимости замените фоновое изображение в `style.css`. Сейчас оно загружается с Unsplash, поэтому для него требуется интернет.

## Как обновлять сайт

Отредактируйте нужный файл и загрузите новую версию в тот же репозиторий с заменой старого файла. GitHub Pages автоматически опубликует обновления после обработки изменений.

## Важно

Сайт публичный: любой человек, у которого есть ссылка, сможет его просматривать. Не размещайте здесь личные данные, пароли или закрытую служебную информацию.
